Module Hermest.Lexicon_types

AT Protocol Lexicon type definitions.

This module defines the OCaml representation of AT Protocol Lexicon schemas as specified in the Lexicon specification.

Lexicons define the schema for data and RPC methods in the AT Protocol. Each lexicon document has a unique NSID (Namespaced Identifier) and contains type definitions.

Type System

The lexicon type system includes:

  • Primitives: string, integer, boolean, bytes
  • Complex: blob, cid-link, array, object, ref, union
  • Special: token, unknown
  • Methods: query, procedure, subscription
  • Data: record
  • Auth: permission-set (OAuth scopes)

Example Lexicon

A simple lexicon JSON:

{
  "lexicon": 1,
  "id": "app.bsky.feed.post",
  "defs": {
    "main": {
      "type": "record",
      "key": "tid",
      "record": {
        "type": "object",
        "required": ["text", "createdAt"],
        "properties": {
          "text": {"type": "string", "maxLength": 300},
          "createdAt": {"type": "string", "format": "datetime"}
        }
      }
    }
  }
}
